# Corazones de clase

App para que la profe reparta corazones a sus alumnos. Cada día todos empiezan con 0.
Los nombres se guardan solo en el dispositivo de la profe (localStorage), no hay servidor.

- Web: carpeta `docs/` (GitHub Pages).
- Pruebas: `node pruebas/test.js <url>` (necesita `playwright-core` y Chrome).
